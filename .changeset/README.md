# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a tool to manage versioning and changelogs. Read the full documentation at https://changesets.dev.

We also have a quick list of common questions to get you started engaging with this project in our [FAQ](https://changesets.dev/faq).

## Patch only

These packages are on `0.0.x`. Every changeset in this repo asks for `patch` and nothing else:
a `minor` would publish `0.1.0` and a `major` would publish `1.0.0`, neither of which is where
this is going yet, and a published version number cannot be taken back.

[`scripts/check-changesets.ts`](../scripts/check-changesets.ts) enforces this. It runs as a
`pre-commit` hook if your clone has installed, and again in CI and in the release workflow,
where it gates `changeset version`. So a `minor` or a `major` cannot reach a release whether or
not the hook was there to catch it locally. If you are writing a changeset by hand, write
`patch`.
